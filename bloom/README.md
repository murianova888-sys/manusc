# When the Verb Is the Label — data, audit protocol and code

Supplementary repository for the paper

> **When the Verb Is the Label: A Construct-Validity Audit of Bloom’s Taxonomy Annotations in
> Template-Based and Large Language Model-Generated Discrete Mathematics Item Banks**

It contains the three item banks studied in the paper, the audit rubric and annotation conventions,
all analysis scripts, the derived datasets (including the 28 items recommended for relabelling and the
30 boundary cases), the trained model, and every number and figure reported in the paper.

> affiliations and the citation will be added after acceptance.

## The study in brief

Automated Bloom-level classifiers are routinely reported at 85–95 % accuracy, while human raters agree on
the same task at κ ≈ 0.20. The paper tests whether this gap reflects the models or the item banks they are
trained on. 980 items of an English-taught discrete mathematics course were audited:

| | Corpus A | Corpus B | Corpus C |
|---|---|---|---|
| What it is | template-based bank | Corpus A split into six per-level files | bank generated by a large language model |
| Items | 500 (only 48 distinct wordings) | 500 (same items as A) | 480 (16 topics × 6 levels × 5) |
| Origin of the Bloom label | derived automatically from the template | copied from A | level requested from the generator |

Main results (all reproduced by the scripts in `analysis/`):

- **Corpus A cannot be audited:** 249 of 500 items (49.8 %) contain no material needed to perform them
  (templates T3–T5: no problem, no example, no solution is given). Corpus B is label-identical to A
  (agreement 1.000) and is not an independent annotation.
- **Corpus C:** declared labels agree with the human audit at κ = 0.930, but the 28 disagreements (5.8 %)
  are one-sided — 23 overstatements vs 5 understatements (sign test p = 0.00046) — and concentrate at
  Analyze (13.8 %) and Create (15.0 %); 22 of the 28 resolve to Apply.
- **Classifier vs one word:** the best model (linear SVM) reaches 0.905 accuracy but does not beat the rule
  “first word → most frequent level” (0.902 vs 0.917 out-of-fold, McNemar p = 0.419). Masking the first word
  costs 20 points (0.902 → 0.700).
- **Transfer:** a model trained on Corpus A classifies Corpus C at only 0.415; the reverse direction gives 0.978.
- **New artefact in generated items:** item length explains 48 % of the variance in level (η² = 0.483).

## Audit protocol

Every item of Corpus C was classified by two annotators against the cognitive-process dimension of the
revised taxonomy (Anderson & Krathwohl, 2001), taking **the operation the item requires** — not the verb used
to request it — as the unit of judgement.

- **Annotator M** (protocol-guided human reading) — `analysis/manual_audit.py`. Items not listed there were
  judged to match their declared level. The file also holds the 30 boundary cases with their stricter
  alternative reading (sensitivity analysis) and the list of non-actionable templates of Corpus A.
- **Annotator R** (rule-based rubric) — `analysis/rubric.py`. Ordered regular-expression rules implementing
  the same conventions, evaluated from Create downwards. It makes the rubric auditable and re-runnable on
  new items; it is a reproducibility check, not an independent judgement.

Boundary conventions, fixed **before** annotation:

| | Convention | Level |
|---|---|---|
| K1 | “Determine which of the following are X”, settled by applying a definition | Apply (executing) |
| K2 | Comparison at the level of definitions / trade-offs across several criteria | Understand / Analyze |
| K3 | “Prove *standard result* using *named technique*” / non-routine construction | Apply / Create |
| K4 | Reproducing a canonical artefact (RSA from given p, q; bijection (0,1)→(0,5); merging sorted lists) / artefact under non-trivial constraints | Apply / Create |
| K5 | Checking the correctness of a supplied claim or solution, whatever the verb | Evaluate (checking) |
| K6 | Item whose construction is already specified in its own wording | Apply |

## Reproducing the results

Python 3.13 (also tested with 3.12).

```bash
pip install -r requirements.txt
cd analysis
python 00_check_corpus_b.py
python 01_audit.py
python 02_compare.py
python 03_model.py
python 04_stats.py
python 05_deliverables.py
python 06_figures.py
```

Scripts must be run from `analysis/` in this order; each reads the outputs of the previous ones.
Intermediate files (`gen_audited.csv`, `orig_audited.csv`, `oof_pred*.npy`) are created in `out/` and are
excluded from version control. All random seeds are fixed (42). The full pipeline takes a few minutes on a laptop.

A clean re-run reproduces all reported numbers. Two platform-dependent differences are expected and harmless:
the committed files were written on Windows, so a re-run on Linux or macOS produces LF instead of CRLF line
endings; and the lbfgs solver of logistic regression may change the fold-to-fold standard deviation of that
one model in the third decimal place (its mean accuracy, 0.872, is unchanged). Figures and the pickled
model may differ at the byte level across machines while showing the same results.

## Using the trained model

The pickled pipeline needs scikit-learn 1.9.1 and the `HandFeats` transformer defined in `03_model.py`.
`predict.py` provides it:

```bash
cd analysis
python predict.py "State the definition of a bijection." "Construct a truth table for (p -> q) and (q -> p)."
# Remember    State the definition of a bijection.
# Create      Construct a truth table for (p -> q) and (q -> p).
```

```python
from predict import predict          # run from analysis/
predict(["Explain why the empty set is a subset of every set."])   # ['Understand']
```

The second example illustrates the paper’s main point: constructing a truth table is an Apply task, but the
model labels it Create because it opens with *construct*. The model is released to make the results
reproducible, **not** as a validated tool for tagging items by cognitive level.

## Limitations

- The audit of Corpus C was performed by a single annotator with the declared labels visible; the true
  disagreement rate is plausibly higher than 5.8 % (11.7 % under the strict reading of boundary cases).
- Corpus C is balanced by construction (80 items per level), which inflates chance-corrected agreement
  relative to real item banks.
- One domain (discrete mathematics), one generator, one language (English). The diagnostics transfer to other
  banks; the effect sizes do not.
